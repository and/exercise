Firebase Setup Guide

This app needs Firebase for login and data sync. Follow these steps:

  1. Go to console.firebase.google.com
  2. Click Add Project, name it anything (e.g. "leg-tracker")
  3. Once created, click the Web icon (</>) to add a web app
  4. Copy the firebaseConfig object
  5. Go to Authentication > Sign-in method, enable Google
  6. Go to Firestore Database > Create database (start in test mode)
  7. Open this HTML file and replace the firebaseConfig object near the bottom
{
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_PROJECT.firebaseapp.com",
  projectId: "YOUR_PROJECT_ID",
  storageBucket: "YOUR_PROJECT.appspot.com",
  messagingSenderId: "YOUR_SENDER_ID",
  appId: "YOUR_APP_ID"
}
