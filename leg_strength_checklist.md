# LEG STRENGTH DAILY CHECKLIST
### ACL Recovery — 4-Week Starter Program
### Schedule: 3x per week (e.g., Mon / Wed / Fri)

---

## WEEKS 1-2: FOUNDATION (~20 min)

| Done | Exercise | Sets x Reps | Cue |
|------|----------|-------------|-----|
| [ ] | **Glute Bridges** | 3 x 15 | Squeeze glutes at top, weight in heels |
| [ ] | **Wall Sits** | 3 x 30 sec | Back flat on wall, knees at 90 degrees |
| [ ] | **Standing Hamstring Curls** (L) | 3 x 12 | Hold counter, slow 3-sec lowering |
| [ ] | **Standing Hamstring Curls** (R) | 3 x 12 | Hold counter, slow 3-sec lowering |
| [ ] | **Clamshells** (L) | 3 x 15 | Feet together, lift top knee only |
| [ ] | **Clamshells** (R) | 3 x 15 | Feet together, lift top knee only |
| [ ] | **Terminal Knee Extension** (L) | 3 x 15 | Band behind knee, straighten FULLY |
| [ ] | **Terminal Knee Extension** (R) | 3 x 15 | Band behind knee, straighten FULLY |
| [ ] | **Single-Leg Balance** (L) | 3 x 30 sec | Light wall touch if needed |
| [ ] | **Single-Leg Balance** (R) | 3 x 30 sec | Light wall touch if needed |

**Rest between sets:** 30-45 seconds

---

## WEEKS 3-4: BUILDING (~25 min)

| Done | Exercise | Sets x Reps | Cue |
|------|----------|-------------|-----|
| [ ] | **Mini Squats** (band above knees) | 3 x 15 | Sit back, knees press outward |
| [ ] | **Glute Bridges** (band above knees) | 3 x 15 | Press knees apart at the top |
| [ ] | **Lateral Band Walks** (L) | 3 x 10 steps | Stay low, don't stand up between steps |
| [ ] | **Lateral Band Walks** (R) | 3 x 10 steps | Stay low, don't stand up between steps |
| [ ] | **Standing Hamstring Curls** (L) | 3 x 12 | Medium band, slow descent |
| [ ] | **Standing Hamstring Curls** (R) | 3 x 12 | Medium band, slow descent |
| [ ] | **Terminal Knee Extension** (L) | 3 x 15 | Increase band resistance |
| [ ] | **Terminal Knee Extension** (R) | 3 x 15 | Increase band resistance |
| [ ] | **Reverse Lunges** (L) | 3 x 8 | Bodyweight first, step BACK |
| [ ] | **Reverse Lunges** (R) | 3 x 8 | Bodyweight first, step BACK |
| [ ] | **Single-Leg Balance** (L) | 3 x 30 sec | Try eyes closed |
| [ ] | **Single-Leg Balance** (R) | 3 x 30 sec | Try eyes closed |

**Rest between sets:** 30-45 seconds

---

## STOP RULES

- Sharp pain during any exercise --> STOP that exercise
- Pain above 4/10 --> reduce resistance or reps
- Knee swelling after session --> ice 15 min, reduce intensity next session
- Knee giving way or buckling --> see your doctor

---

## 3 DAILY REMINDERS

1. **Always do BOTH legs.** Notice the difference. Close the gap.
2. **Slow and controlled beats fast and sloppy.** Every time.
3. **Showing up 3x/week matters more than any single workout.**

---

*Keep walking your 10k steps. Add this program on top.*
*Re-assess after 4 weeks. Progress to heavier bands and single-leg work.*
*Consult a physiotherapist if pain persists or worsens.*
